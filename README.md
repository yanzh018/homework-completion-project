# 作业补完计划：个人笔迹工作台

这是一个本机运行的中文网页应用。它把上传的手写作业拆成字形候选，由 AI 优先校对并将可靠的真实手写结果自动入库，再用真实字形及单独标记的推测字形排版答案。题目文本、答案原文、公式结构、作答区域、字形来源和导出审计分别保存。

## 启动

### Windows

安装 Python（本项目在 macOS 上使用 Python 3.14 验证；Windows 尚未实测），将项目下载并解压到本机，双击 `start-windows.bat`。首次启动会创建 `.venv` 并安装依赖，需要联网；安装 Python 时可勾选将 Python 加入 PATH。也可在项目文件夹的命令提示符中运行：

```bat
start-windows.bat
```

启动后在浏览器访问 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)，保持启动窗口打开；按 `Ctrl+C` 或关闭窗口停止。Windows 不支持项目使用的 Apple Vision 本地 OCR，云端识别需另行配置兼容的视觉服务。

### macOS

在 macOS 上双击 `启动墨迹.command`，或在终端运行：

```bash
cd /path/to/project
./start.sh
```

浏览器访问 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。启动窗口需要保持打开；按 `Control+C` 停止。首次启动会创建 `.venv` 并安装 `requirements.txt` 中的依赖；macOS 上有 Swift 编译器时自动编译本地 Apple Vision OCR。此项目在当前 Mac 上用 Python 3.14 验证。其他系统可以运行服务和手动标注，但没有 Apple Vision 时不会提供本地自动文字识别。

应用只监听本机 `127.0.0.1`。`data/` 保存上传原件、字形、作业、导出、数据库及可选的云端配置。刷新或关闭页面后，已保存的内容仍在。备份时可复制整个 `data/`；如果保存过 API 密钥，备份也会包含该密钥。

## AI 优先与服务设置

默认预设为 DeepSeek 的 `https://api.deepseek.com` / `deepseek-flash`，默认选择 AI 优先。进入“更多工具 → AI 服务设置”填写自己的 API 密钥，再保存配置。没有密钥时页面会明确显示未接通，自动识题和解答不会以本地 OCR 或示例答案冒充 AI 结果。必要的页面处理、笔迹排版和 PDF 生成在本机完成。也可填写其他兼容 Chat Completions 的服务和视觉模型。

启用并配置视觉服务后：

1. 导入旧作业时，每页的去印刷层笔迹图片会供 AI 定位和识别。随后默认批量发送候选及原文局部让视觉模型校对：模型判为可靠的真实手写样本还会经过独立视觉复核，复核图同时显示目标框的周围笔迹和最终裁剪。只有标签一致、裁剪完整且边缘没有明显截断的样本才自动入库。自动拆字只在相邻字之间找到连续空白竖缝时进行；连笔或切线穿过笔画时保留整词候选。印刷、批改和不确定项会自动排除或保留，不需要逐个调整。可在“更多工具 → AI 服务设置”关闭自动校对。
2. 导入新作业时，视觉 AI 逐页识别并再次复查题目，必要时读取上一页以恢复共同题干；每题交给 AI 解答并独立复核。DeepSeek 的答案复核采用 JSON 输出模式，空回复或格式错误最多自动再试两次。程序利用原页的空白区域辅助布局，空间不足时请 AI 保留必要步骤并精炼答案。可读取的分题标记若未被题目框覆盖会阻止本页完成。每页最多处理 12 题；失败或不确定时保留已有结果并提示，不作为完整作业导出。AI 复核并不保证答案正确。
3. 如果生成检查发现遮挡、区域重叠、字形碰撞或空间不足，系统会把该页原题、含生成笔迹的预览、题目答案和检查结果发给同一视觉服务，自动调整一次位置；仍无法解决时明确提示并保留全部步骤。位置调整本身不会另外缩小字号或增加页数；自动字高另由样式设置控制。
4. 自动补字和本稿使用推测字形默认开启；至少有 4 个真实字形时，缺字会参考最多 16 个已入库真实字形按每批最多 3 个推测补齐，一次任务最多 90 个缺字。发送个人笔迹字形前单独确认。新生成的字形还会以不显示目标标签的图片发送给同一 AI 服务独立辨认，只有复核标签一致、完整且置信度达标的字形才自动使用；未通过的保留为待处理。旧版字形在生成预览时会列入本次实际使用字形的独立复核，复核通过前阻止导出。推测 `z` 缺少底横，或不等号方向与标签不一致时不会自动使用；推测的 `ℝ` 不直接使用，可用真实 `R` 与结构线组成实数集符号。部分字形也可由真实笔迹在本地衍生，界面和审计会明确标记其来源，仍不计入对应字符的真实样本。推测字形不保证正确或相似，结果与真实字形分开标记。可在设置中关闭自动补字，在作业样式中关闭推测字形。

每次云端任务开始前，界面显示服务地址、模型、本次外发的图像或文字和请求上限。若需要发送真实笔迹字形或包含答案的个人笔迹预览，会再次说明并单独确认。旧作业笔迹图可能含姓名、学号和作业内容；新作业图也可能含这些信息。云端响应提供 `usage` 时，系统仅记录 token 用量；应用不填写单价，也不计算费用。

AI 识别、批量校对和解答运行时请保持页面打开；可以在进度条处停止 AI 处理。停止或失败时已完成的页和答案保留，未完成页会标记并阻止不完整导出。在预览页点击“继续 AI 处理未完成部分”可继续，已完成答案不会被覆盖。样本的续处理入口仍在“我的笔迹”。

服务方能力可能变化，请以 [DeepSeek 图像接口](https://api-docs.deepseek.com/guides/vision/)为准。已使用当前配置在 Safari 处理一份真实四页作业，包括识题、解答、复核、补字和位置调整；模型的整体识别准确率与笔迹相似度仍需逐次核查。自动化回归测试中的云端服务为本机模拟。

## 使用流程

1. 在“我的笔迹”确认选择亲笔旧作业；根据提示确认识别和校对，候选由系统自动处理。配置服务、选择文件和切换页面仍需要基本界面操作。
2. 在“AI 处理作业”确认选择新作业，确认外发范围后自动识题、解答并生成预览。已保存作业可以继续处理。
3. 如果预览提示字形待复核，点击“确认继续自动复核字形”。系统按实际使用的字形分批发送局部图片，检测到截断、邻字或标签不一致时自动排除；替换后出现的新字形需要继续复核。原始样本不会被删除。
4. 如果仍有缺字或布局问题，按“确认继续”让 AI 补字或自动调整。缺字、未复核和碰撞会阻止 PDF 生成，不能用灰色占位字绕过。完成检查后，再核对题目、答案与各页预览，确认生成和下载。

浏览器自动流程隐藏手动框选、改标签、拖动位置及字形编辑入口；保留现有数据和内部兼容接口。失败时保留进度并说明原因，不能保证所有字形或作业都能自动完成。模型识别与复核可能误判，生成的笔迹不等于本人亲笔书写。

自然连笔可以作为一个完整标签入库。系统优先使用真实连笔或字形，并保留多个版本。AI 补字不会进入真实库，也不会成为之后的风格统计或 AI 参考来源。源于本系统的生成 PDF 带有标记，不能再次导入为真实样本；外部软件移除标记或截图后形成的文件无法可靠识别其来源，应由使用者自行维护真实来源。

生成默认参考已确认真实字形的中位笔画宽度，对字形按输出尺寸进行有限校准，并让公式线条保持接近的粗细；边缘截断候选不参与字形库和风格统计。真实字形、完整连笔和推测字形输出时都可加透明边距，再进行受笔画完整性约束的粗细校准；推测来源仍单独标记，原始图像不改变。真实样本不足时使用默认估计。正文为同类数字和上伸字使用统一字高，按个人样本估计小写字及下伸笔画比例。公式中的短小写变量优先参考同页同行真实 `x` 与数字的高度比例，配对不足时使用默认值。校准会保护独立笔画和字腔，因此不保证每一笔的宽度完全相同。

输出字形按真实样本中的字高和基线比例排版。普通字母和完整连笔会对齐视觉基线；确有下伸的笔画仍保留。整词的下伸比例异常且所有单字都有真实样本时，可用真实单字重排，原始连笔仍留在库中。单词内按实际笔画轮廓调整间距并检查相撞；输出只裁去透明边缘，不删除分离的笔画，粗细校准也会避免切断或抹去笔画。旧样本会在使用时补查原页边界；单字若存在可能属于邻字的分离墨迹，会保守跳过而不是硬裁，也不会作为 AI 补字参考。几何检查无法识别所有连在一起的邻字，视觉 AI 的判断仍可能出错。

裁剪完整、尺寸合理的真实整词优先整体复用，并参考原笔画估计下伸部分和基线；不会把完整单词强行嵌入另一单词。相对字数异常窄的整词在各单字均可用时改用单字组合。旧样本接近裁剪边缘时，系统会回查原页，区分完整笔画贴边和笔画跨出边界；仍无法确认的样本不会放行。整词及恢复的旧样本依然需要通过独立复核，原始图像和来源不变。未手动修改的 AI 草稿空间不足时，会先尝试收紧段落空行；启用自动字高且所有非空答案都是未手动修改的 AI 草稿时，还会尝试对整份草稿以 0.5 pt 为步长统一缩小字高，不低于原设的 80%，也不低于 12 pt。当前字高没有缩小空间时该选项不可操作，已保存的选择仍会保留；小于 12 pt 的字高不会因此被放大。只有调整后能放入区域才采用，并在预览中提示实际字高；答案文字、公式和步骤不变。审计以 `auto_compacted_blank_lines` 和 `effective_font_size` 记录调整。手动修改字高会关闭自动字高调整，也可在“调整书写样式”中重新开启。达到下限仍放不下时继续提示，不丢步骤。

公式中的运算符、函数名、小数点和相邻括号按用途调整间距；相邻公式字形的笔画若实际相碰，会自动扩大必要间距，并在超出区域时提示。英文单词内部字母更紧凑，不同单词之间保留更明显的间隔；间距仍可在“预览与导出 → 调整书写样式”中调整。新作业的“字距倍数”默认 0.7；已保存的设置会保留，符号和括号的间距也随之调整。旧排版生成的预览需要重新生成，答案原文不变。

数值与常见单位（如 `m`、`kg`、`in^3/s`）会作为整体换行；原文中独立一行的可识别单位也会与前面的数值排在同一行。答案原文和结构不变，空间不足时会提示调整区域。未识别的特殊单位可与数值放在同一对公式标记中，例如 `$1296\,\mathrm{in}^3/\mathrm{s}$`。

只有下一行以顶层等号开头、且上一行有顶层等号时，才将其作为明确续算对齐，例如 `$y'=x+x$` 换行 `$=2x$`。其他相邻公式默认自然起笔，不自动推断两条完整等式是否等价；分式、括号或矩阵内部的等号不作为对齐点。对齐后空间不足时会提示调整作答区域，答案原文不变。

## 答案与公式

正文直接输入，公式可用成对的 `$…$`、`\(…\)` 或 `\[…\]` 包围，也支持 `$$…$$` 和起止 `$` 各占一行的跨行公式。示例：

```text
Let $x=3$.
$f'(x)=\frac{x^{2}+1}{\sqrt{x+3}}$
$x_{1}^{2}+y_{2}$
$\left[\frac{1}{x}\right]$
$\begin{bmatrix}1&2\\3&4\end{bmatrix}$
$\sqrt[3]{x+1}$
$\vec{u}^{T}\vec{v}$
$m\, \text{by}\, n$
```

公式中的单词用 `\text{...}` 表示，例如 `\text{by}`，与单独的数学变量分开排版。支持分式、上下标、根号、圆括号、中括号、导数撇、向量箭头（`\vec{u}` 或 `\overrightarrow{u}`）、`matrix` / `pmatrix` / `bmatrix` 和部分常用符号。向量箭头随字形大小调整，支持与上下标组合；有真实箭头笔画时优先复用，否则绘制结构线条。矩阵中括号优先使用真实笔迹，没有样本时绘制结构线条。根号、分数线和括号按内容尺寸调整；有经过分离与校准的完整根号笔画时，优先复用并伸长本人横线，否则使用个人根号头并补画横线，无样本时使用结构线条。圆括号优先使用可用的个人笔迹。字形分离保留原文件、位置和矢量笔画编号，不能可靠分离的候选留待处理。其他 TeX 命令会显示错误，并保留可编辑草稿；必须修正后才能导出。排版优先使用真实字形；启用 AI 推测字形后，也可用已允许的推测字形补缺，并在预览和审计中标明。仍缺少可用字形时阻止导出；旧设置中的灰色印刷参考字只用于预览，并在审计中记录，非 ASCII 占位可能显示为问号。不会为了塞入区域自动删除步骤或无限缩小。

集合关系 `\in`、`\notin`、并集 `\cup`、等价 `\iff`、近似 `\approx`、半开区间及常见数集 `\mathbb{R}` 等按对应数学结构保存和显示。缺少真实字形时，部分符号使用结构线；实数集符号可由真实 `R` 与结构线组成，其余缺字仍须补齐。

题目和答案的可读预览使用浏览器本地 MathML，不依赖网络；不能解析的内容会保留原文并提示检查。常见的 Markdown 粗体、行首标题、列表和行内代码标记只用于展示，生成的书写内容同样不包含这些标记，保存的原文不变。预览生成进度按实际排版、逐页检查与图片保存阶段更新；刷新页面后可继续查看同一任务，关闭本地服务则需要重新生成。

## 已知问题与限制

以下根据项目现有记录整理，最后核对日期为 2026-11-03；这不是对所有输入或所有环境的完整测试。具体经过和先前已修复的问题见 [验证记录](验证记录.md)。

### 尚未解决的验证问题

- **真实文件核心回归尚未通过。** 2026-11-02 的记录显示，真实材料测试中部分旧测试候选被裁剪安全检查判为可能截断；核对原稿后发现部分候选确实越过边界。专项测试通过不能代替完整核心回归通过。应更换或修正测试样本并复测，不应为了通过测试放宽保护。
- 真实材料的历史测试结果不能代表当前版本的完整测试结果，也不能证明真实云端模型质量。为保护隐私，相关测试及样本不在公开仓库中。

### 识别与字形

- 本地 OCR 不是可靠的数学公式识别器，可能漏字或给出过紧的词框；复杂连笔、点号、指数及浅色笔画尤其容易识别不全。自动拆字只在连续空白竖缝处进行。
- 黑色印刷、手写及黑色批改在扫描件中无法由本地处理可靠区分；视觉 AI、红色过滤和纠偏也可能误判，尤其是浅色笔迹和倾斜较大的照片。
- 字形可能混入相邻笔画、被截断或被错误标注；几何检查不能识别所有连在一起的邻字，AI 双重校对也可能误判。验证记录中曾出现通过复核但混入邻字的样本。需要对照原稿检查，不确定样本会留待处理。
- 可用真实字形不足时可能缺字并阻止导出。AI 推测字形可能不完整、不易辨认或不像本人；已有检查不能覆盖所有错误。粗细、字高和基线是有限估计，不保证与原笔迹完全一致。
- 矢量分离依赖可读取的 PDF 路径或文字层；复杂排版、混合图片与路径、特殊颜色或无法可靠分离的笔画可能无法自动处理。当前浏览器自动流程隐藏手动框选、改标签及字形编辑入口，遇到这些情况未必能直接在界面修正。
- 项目生成的 PDF 有来源标记，但外部软件移除标记或截图后的文件无法可靠识别；不要把它们当作真实手写样本。

### 题目、答案与排版

- AI 识题、解答、复核及区域定位可能遗漏或出错，尤其是多栏、空间紧张或扫描质量差的页面；逐题独立复核也不保证正确。每页最多处理 12 题，更多题目需拆分页面。
- 位置自动调整只尝试一次；空间不足、字形碰撞或调整失败时，仍可能无法生成 PDF。界面隐藏手动拖动位置入口，无法保证每份作业都能在当前自动流程中完成。
- 碰撞检查主要依据像素重叠、字形边界及可读取的原题文字框；扫描件缺少文字框时更依赖像素检查，不能发现所有遮挡或视觉问题。需逐页对照原题、答案和生成预览。
- 仅支持部分 TeX 命令和矩阵环境；不支持的语法会保留草稿并阻止导出，需改写。未识别的特殊单位可能需要手动与数值放入同一公式。以 PDF 页面旋转属性设置旋转的文件会被拒绝，需先永久应用旋转。
- 生成的笔迹是字形与结构线的合成，不代表本次答案由本人亲笔书写；课程如要求亲笔书写或限制 AI 使用，应遵循课程要求。

### 服务、环境与数据

- 云端服务可能不支持所需图像能力，或返回无效 JSON、空回复、断开连接；重试后仍可能暂停或留下待处理内容。处理时需保持页面打开，失败后应检查并继续未完成部分。
- 自动补字至少需要 4 个真实字形，每次任务最多处理 90 个缺字；生成或复核失败的字形不会因此变为可用字形。
- 本地自动 OCR 依赖 macOS 的 Apple Vision；其他系统没有该能力。当前验证环境是本机 Python 3.14，不能据此保证其他环境的兼容性。
- 云端处理可能发送含姓名、学号、题目、答案或笔迹的图像及文字；以界面每次显示的发送范围为准。`data/` 中的备份可能包含 API 密钥，项目默认不会将它上传至 Git。

## 已尝试解决的问题

下表按问题归纳 [验证记录](验证记录.md) 中截至 2026-11-02 的处理和当时结果。历史测试通过只说明当时检查的范围，不保证当前版本、其他文件或模型输出均正确；仍存在的限制见上一节。

| 问题 | 已采取的措施及记录中的结果 |
| --- | --- |
| HTTPS 证书错误和笼统的连接提示 | 在特定条件下回退到本机证书库，保留证书和主机名校验，区分证书、DNS 和超时错误；专项测试及一次真实连接通过。 |
| AI 校对结果不可靠或混入邻字 | 增加不显示原标签的独立复核、裁剪边界和笔画来源检查；不可靠样本留待处理。小样本和模拟测试有改善，但仍可能误判。 |
| AI 返回无效 JSON、重复编号或服务中断 | 首次校对和答案复核增加有限重试；不可靠批次保留待处理，连续失败时暂停。模拟测试通过，一道题的真实复核续测通过；服务错误仍可能发生。 |
| 中断后进度丢失或覆盖用户编辑 | 保存已完成页面和题目，支持继续处理，并检查并发修改；隔离测试验证已完成答案及人工编辑得以保留。 |
| 题目漏识、跨页上下文丢失或共享题干被误当作独立题 | 加入分题标记检查、上一页上下文复查和共享题干提示；一次真实四页流程完成，但不能保证其他作业无遗漏。 |
| 答案压住原题、区域不足或字形碰撞 | 加强原题和笔画重叠检查，尝试一次自动位置修正；对符合条件的 AI 草稿收紧空行或有限缩小字高。模拟及部分真实页面通过检查，空间不足时仍可能无法导出。 |
| 公式分隔符、集合符号及向量支持不足 | 增加多种公式标记、集合关系、`\\mathbb{R}`、`\\notin`、向量箭头及上下标支持；相关专项测试通过，其他未支持命令仍需改写。 |
| 根号、括号和箭头缺少真实笔迹 | 从原稿分离可用笔画并按内容尺寸调整；无可靠样本时使用结构线。记录中的特定作业通过局部检查，并非所有样本都能自动分离。 |
| 数值与单位断开、续算等号错误对齐 | 常见单位与数值合排；仅对明确以顶层等号开头的续算对齐。专项及特定作业检查通过，特殊单位仍需检查。 |
| 单词字距过大、数学文字与变量混排 | 根据实际笔画调整字距和视觉基线，区分公式文字与变量；记录中的作业和专项测试通过，结果仍依赖样本。 |
| 字形笔画粗细、字高、基线和下伸不一致 | 基于真实样本做有限校准，增加透明边距并保护独立笔画；特定稿件和专项测试显示改善，无法保证所有字形一致。 |
| 自动框截断字形或混入相邻笔画 | 将问题样本移回待处理，从原页重新分离真实路径，并结合原图检查裁剪边界；已检查样本改善，但自动检查并不完备。 |
| 完整连笔被拆开、姓名字形或个别字母错误 | 优先使用边界合理的真实整词；重新分离姓名、`g`、`t`、`5` 等样本并排除污染样本。部分新样本当时仍待独立复核。 |
| 缺字、`E` 与 `∈` 混淆及推测符号不可读 | 补充并区分真实路径，为部分易混淆推测字形增加检查；某次四页预览无缺字，但部分字形和答案仍待复核。 |
| 预览进度不清楚、刷新后状态或旧预览混淆 | 增加按阶段显示的后台进度、刷新后跟踪、旧预览失效及并发保护；浏览器和专项测试通过，服务重启仍会中断任务。 |
| 真实文件核心回归受旧样本裁剪问题阻断 | 保留裁剪安全检查并核对原稿；确认部分旧样本确实越界。最后记录中测试样本尚未修正，完整核心回归仍未通过。 |
